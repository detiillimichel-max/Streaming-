# StreamingTV OIO - Edge Hub

Aplicação modular desenvolvida para consumir **Edge Functions** com carrosséis de conteúdo, navegação home e repositório de ideias.

## Estrutura do Projeto
- `index.html`: Layout principal e marcação de abas.
- `style.css`: Estilização modular em Glassmorphism.
- `app.js`: Lógica de navegação e requisições assíncronas.

Pronto para deploy no **GitHub Pages**!
